# PROJECT_ZERO

> Interactive full-stack developer portfolio built with React, Three.js and Framer Motion.

## 🚀 About

PROJECT_ZERO is my personal developer portfolio designed as an interactive
digital experience rather than a traditional portfolio website.

It showcases my projects, technical stack, development journey and contact
information through a futuristic interface powered by WebGL and motion.

## 🛠️ Tech Stack

- React
- JavaScript
- Three.js
- React Three Fiber
- Framer Motion
- CSS
- Vite

## ✨ Features

- Interactive boot sequence
- 3D Zero Core
- WebGL space environment
- Animated HUD navigation
- Scroll-based sections
- Project showcase
- GitHub project links
- Resume viewer
- Responsive design
- Interactive animations
